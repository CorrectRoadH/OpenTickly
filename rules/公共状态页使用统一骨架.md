# 公共状态页使用统一骨架

独立的认证、邀请、错误和成功状态页应复用 `PublicStatusPage` 或
`PublicMainPanelFrame`，使用 `--track-*` 主题变量，并为可恢复状态提供与文案
一致的操作。不要在公共状态页中另起一套 `slate-*` / `emerald-*` 直接色值，
否则深色主题下会丢失对比度和视觉层级。

该约束涉及路由语义、组件复用和主题对比度，需要跨文件 review，因此保持为
draft 规则。

```grit
language js
`className=$className` where {
  $filename <: r".*apps/website/src/(pages/(auth|members)|routes)/.*\.tsx",
  $className <: r".*(text|bg|border)-(slate|emerald|rose)-.*"
}
```

## 反例

```tsx
<main className="min-h-screen px-4 py-8">
  <AppPanel>
    <h1 className="text-slate-950">{heading}</h1>
  </AppPanel>
</main>
```

## 正例

```tsx
<PublicStatusPage badge={badge} title={heading} tone="error">
  <StatusAction to="/login">{goToLogin}</StatusAction>
</PublicStatusPage>
```
