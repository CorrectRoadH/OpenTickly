language: tsx
level: warn

主题自适应表面上的正文和建议标题使用语义文字色 token，不能用白色作为默认值。
项目原色可用于色点与图标；文字仍须在当前主题表面上达到 4.5:1 对比度。
明确的反色按钮等成对设计需人工审查，不把任意项目色直接当作可读文字色。
下面检查内联文字白色及空值白色回退；Tailwind 类和跨层混色由浏览器对比度验收覆盖。

```grit
language js
or {
  `color: "white"`,
  `$fallback ?? "white"`
} where {
  $filename <: r".*apps/website/src/.*\.tsx"
}
```
