# 异步操作不可静默失败

用户触发邀请、重发邀请、测试邮件等异步操作后，界面必须明确报告成功或失败。
请求入口需要有回归测试证明点击会实际调用 mutation；领域或外部服务失败需要以结构化错误码
到达前端并显示可理解的提示，不能依赖代理可能吞掉正文的 5xx 响应。

跨文件的完整约束仍需 review；当前可执行部分先拦截没有任何本地结果回调的
`mutation.mutate(request)`。调用方应传入 `onSuccess` / `onError`，或改用被明确
`await` / `.then().catch()` 消费的 `mutateAsync`。

```grit
language js
`$mutation.mutate($request)` where {
  $filename <: r".*apps/website/src/.*\.tsx"
}
```
