O [`toggl-cli`](https://github.com/CorrectRoadH/toggl-cli) permite que Claude Code, OpenClaw, Hermes Agent, Codex, Cursor e outros agentes de IA usem o OpenTickly pela linha de comando. Eles podem registrar tempo, iniciar e parar o cronômetro e organizar projetos e tags para você.

Ele tem duas partes:

- `toggl`: a ferramenta de linha de comando em si
- `SKILL.md`: um arquivo de skill que ensina o seu agente a usá-la

## Instalação

```bash
npm install -g @correctroadh/toggl-cli

npx skills add CorrectRoadH/toggl-cli
```

## Configuração

A CLI funciona tanto com o Toggl quanto com o OpenTickly, e por padrão conversa com o Toggl. O Toggl só permite 30 requisições de API por hora, e um agente consegue gastar isso em um minuto, por isso recomendamos usar com o OpenTickly.

Para apontar para a sua instância, acrescente `--api-type opentoggl` e `--api-url` ao fazer login:

```bash
toggl auth <YOUR_API_TOKEN> --api-type opentoggl --api-url https://sua-instancia.com/api/v9
```

Você encontra o `YOUR_API_TOKEN` no app web do OpenTickly, clicando no seu avatar → Profile → API Token.

Não sabe bem o que fazer com isso depois? Em [Práticas / Fluxo de trabalho](/pt/docs/practices) há alguns exemplos reais: deixar o agente iniciar o cronômetro, passar para ele o seu plano da semana e uma revisão diária feita pela IA à noite.
