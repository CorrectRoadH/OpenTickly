## Comece a registrar

1. Abra **Cronômetro** e descreva o trabalho.
2. Escolha projeto e tags e aperte o botão de reprodução.
3. Pare o cronômetro quando terminar.

Para registrar trabalho passado, crie uma entrada no calendário e ajuste o início e o fim. O campo **Modo de entrada manual** do perfil não muda atualmente a barra do cronômetro para o modo manual.

## Atalhos

Digite `@` para escolher projetos ou `#` para tags, no começo da descrição ou após um espaço. Continue digitando para filtrar, escolha com as setas e confirme com Enter. Escape fecha o seletor.

Em **Atalhos de teclado** no perfil, você pode desativar cada opção:

- **Permitir uso do atalho @ para atribuir um Projeto no campo de Descrição do Cronômetro**
- **Permitir uso do atalho # para atribuir uma Tag no campo de Descrição do Cronômetro**

Fora dos campos de entrada, `n` leva o foco à descrição, `s` para o cronômetro e `?` mostra os atalhos.

## Calendário e lista

Em **Calendário**, arraste sobre um horário vazio para criar um registro. Arraste um registro existente para movê-lo ou sua borda para mudar a duração. Clique para editar; o botão direito oferece ações como **Duplicar**, **Dividir**, **Copiar descrição** e **Excluir**.

Em **Visualização em lista**, marque vários registros e escolha **Editar** para alterar descrição, projeto, tags, data ou status faturável de uma vez. Confira a seleção antes de salvar.

## Favoritos

Clique com o botão direito em um registro do calendário e escolha **Fixar como favorito**. Abra a barra lateral com **Alternar metas e favoritos** e clique em um favorito para iniciar outro cronômetro com a descrição, o projeto e as tags salvos.
