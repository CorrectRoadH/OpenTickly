[`toggl-cli`](https://github.com/CorrectRoadH/toggl-cli) pozwala Claude Code, OpenClaw, Hermes Agent, Codexowi, Cursorowi i innym agentom AI korzystać z OpenTickly z wiersza poleceń. Mogą za Ciebie rejestrować czas, włączać i zatrzymywać timer oraz zarządzać projektami i tagami.

Składa się z dwóch części:

- `toggl`: samo narzędzie wiersza poleceń
- `SKILL.md`: plik umiejętności, który uczy agenta, jak z niego korzystać

## Instalacja

```bash
npm install -g @correctroadh/toggl-cli

npx skills add CorrectRoadH/toggl-cli
```

## Konfiguracja

CLI działa zarówno z Toggl, jak i z OpenTickly, a domyślnie łączy się z Toggl. Toggl pozwala tylko na 30 zapytań do API na godzinę, a agent potrafi je zużyć w minutę, dlatego polecamy używać go z OpenTickly.

Żeby wskazać swoją instancję, przy logowaniu dodaj `--api-type opentoggl` i `--api-url`:

```bash
toggl auth <YOUR_API_TOKEN> --api-type opentoggl --api-url https://your-instance.com/api/v9
```

`YOUR_API_TOKEN` znajdziesz w aplikacji webowej OpenTickly: awatar → Profile → API Token.

Nie wiesz, co dalej? W [Praktykach / Przepływie pracy](/pl/docs/practices) jest kilka prawdziwych przykładów: agent włączający timer, przekazanie mu planu tygodnia i wieczorne podsumowanie dnia przez AI.
