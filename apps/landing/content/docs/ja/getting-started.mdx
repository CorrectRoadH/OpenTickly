空のアカウントから、役に立つ最初のレポートまで進めるガイドです。[デモ](https://track.opentoggl.com)を試すか、[Docker セルフホストガイド](/ja/docs/self-hosting)に沿って自分の環境へ導入してください。

## ワークスペースを準備する

1. アカウントを登録し、初期設定で作られたワークスペースを開きます。
2. チームが記録を始める前にタイムゾーンを確認します。
3. プロジェクト別に集計するなら、クライアントとプロジェクトを作成します。
4. メンバーを招待し、ロールを確認します。

ワークスペースには、プロジェクト、クライアント、タグ、メンバー、単価、時間エントリが含まれます。

## 記録して確認する

**タイマー**を開き、具体的な説明、プロジェクト、任意のタグを設定して開始し、作業終了時に停止します。開始・終了時刻が分かっている場合は手動入力を使います。

次に **レポート** で期間を選び、合計を確認します。プロジェクト、クライアント、メンバー、タグ、請求可否、説明でグループ化または絞り込みできます。

## 次のステップ

- 既存データは [Toggl から移行](/ja/docs/migrate-from-toggl)します。
- CLI やスクリプトは [Toggl API 互換ガイド](/ja/docs/api-compatibility)で接続します。
- [toggl-cli と AI エージェント](/ja/docs/ai-integration)で記録を自動化します。

最初は、一貫して使える少数のプロジェクトとタグだけを用意してください。レポートで答えたい質問が増えたときに構造を追加します。
