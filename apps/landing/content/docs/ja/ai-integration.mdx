[`toggl-cli`](https://github.com/CorrectRoadH/toggl-cli) を使うと、Claude Code、OpenClaw、Hermes Agent、Codex、Cursor などの AI エージェントが、コマンドラインから OpenTickly を操作できるようになります。時間の記録、タイマーの開始・停止、プロジェクトやタグの管理をエージェントに任せられます。

中身は 2 つです。

- `toggl`：コマンドラインツール本体
- `SKILL.md`：エージェントに使い方を教えるスキルファイル

## インストール

```bash
npm install -g @correctroadh/toggl-cli

npx skills add CorrectRoadH/toggl-cli
```

## 設定

この CLI は Toggl と OpenTickly の両方で使えますが、デフォルトの接続先は Toggl です。Toggl の API は 1 時間に 30 回までしか呼べず、エージェントだと 1 分で使い切ってしまうこともあるので、OpenTickly と組み合わせて使うのがおすすめです。

自分のインスタンスにつなぐには、ログイン時に `--api-type opentoggl` と `--api-url` を付けます。

```bash
toggl auth <YOUR_API_TOKEN> --api-type opentoggl --api-url https://your-instance.com/api/v9
```

`YOUR_API_TOKEN` は、OpenTickly の Web アプリでアバター → プロフィール → APIトークン から確認できます。

設定できたら何をすればいいか迷ったら、[実践 / ワークフロー](/ja/docs/practices) を見てみてください。エージェントにタイマーを任せる、週の計画を渡す、毎晩 AI に振り返りをさせる、といった実際の使い方を紹介しています。
