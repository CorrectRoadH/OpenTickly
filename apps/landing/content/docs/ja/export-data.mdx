---
title: "データのエクスポート"
description: "ワークスペースのアーカイブと時間記録を取得し、Toggl Track 用に整えます。"
---

## ZIP をダウンロードする

1. ワークスペースの **設定** → **データエクスポート** を開きます。
2. **エクスポートする項目を選択：** で必要な項目を選びます。
3. **Export** をクリックします。

ZIP には `manifest.json` と、選んだ項目の JSON が入ります。プロジェクト、プロジェクトメンバー、タスク、クライアント、タグ、ワークスペースメンバー、組織のグループ、設定、保存済みのレポート定義を選べます。一部の選択肢は **projects_users**、**project_tasks**、**team**、**teams**、**workspace_settings**、**custom_reports**、**scheduled_reports** と表示されます。プロジェクトメンバーは `projects_users/<project-id>.json`、ワークスペースメンバーは `workspace_users.json` に入ります。定義を出力しても、レポートの定期送信が使えるようにはなりません。

ZIP に時間記録は含まれません。インスタンスの復旧には[データベースのバックアップ](/ja/docs/backup-and-upgrade)を使ってください。

## 時間記録をダウンロードする

1. **タイムエントリをエクスポート** で **開始日** と **終了日** を選びます。
2. **エクスポート形式** で **CSV** または **PDF** を選びます。
3. **エクスポート** をクリックします。

対象はログイン中のアカウントの指定期間の記録で、ワークスペースをまたぎます。全メンバーの記録ではありません。ワークスペースを切り替えても範囲は絞られないため、プロジェクトとクライアントを確認してください。計測中の記録は除外されます。CSV 列は `Description,Project,Client,Start,Stop,Duration,Billable,Tags`、時間は `HH:MM:SS` 形式です。PDF は閲覧用です。件数を確認し、長期間なら分割して出力します。

## Toggl Track に戻す

CSV はそのままではインポートできません。表計算ソフトで整えます。

1. `Email` 列を追加し、各記録の所有者の Toggl メールアドレスを入力します。
2. 適切なタイムゾーンで `Start` を `Start date` と `Start time` に分け、元の `Start` と `Stop` を削除します。
3. 説明、プロジェクト、クライアント、時間、請求対象の状態、タグを残して UTF-8 CSV で保存します。[Toggl のインポートガイド](https://support.toggl.com/en-us/article/editing-and-uploading-a-csv-file-bk155h/)も確認してください。
4. Toggl のワークスペース管理者として少量を試し、日付と合計を比較してから残りを取り込みます。

ZIP は Toggl の復元用ファイルではありません。CSV では権限、設定、レポート、添付ファイルは移せず、この時間記録の出力にはタスクや単価もありません。請求対象の取り込みは Toggl のプランに依存します。各メンバーが自分の記録を出力してください。

[レポート](/ja/docs/reports)の **エクスポート** は集計結果の出力で、時間記録のインポートには使えません。
