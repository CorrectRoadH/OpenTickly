[`toggl-cli`](https://github.com/CorrectRoadH/toggl-cli)를 쓰면 Claude Code, OpenClaw, Hermes Agent, Codex, Cursor 같은 AI 에이전트가 커맨드라인으로 OpenTickly를 다룰 수 있습니다. 시간 기록, 타이머 시작과 정지, 프로젝트와 태그 관리를 대신 해 줍니다.

구성은 두 가지입니다.

- `toggl`: 커맨드라인 도구 자체
- `SKILL.md`: 에이전트에게 이 도구 쓰는 법을 알려 주는 스킬 파일

## 설치

```bash
npm install -g @correctroadh/toggl-cli

npx skills add CorrectRoadH/toggl-cli
```

## 설정

이 CLI는 Toggl과 OpenTickly 둘 다 지원하고, 기본값은 Toggl입니다. Toggl은 API 요청을 시간당 30번까지만 허용하는데, 에이전트는 이걸 1분 만에 다 써 버릴 수 있습니다. 그래서 OpenTickly와 함께 쓰는 걸 권장합니다.

내 인스턴스를 쓰려면 로그인할 때 `--api-type opentoggl`과 `--api-url`을 붙이세요.

```bash
toggl auth <YOUR_API_TOKEN> --api-type opentoggl --api-url https://your-instance.com/api/v9
```

`YOUR_API_TOKEN`은 OpenTickly 웹 앱에서 아바타 → **프로필** → **API 토큰**에서 확인할 수 있습니다.

설치는 했는데 뭘 시켜야 할지 모르겠다면 [실천 / 워크플로](/ko/docs/practices)를 보세요. 에이전트에게 타이머 맡기기, 주간 계획 알려 주기, 매일 밤 AI 회고 같은 실제 사용 예가 있습니다.
