---

먼저 **인스턴스 관리 → 구성**에서 공개 **Site URL**을 설정하세요. 이메일 링크와 SAML Service Provider URL이 이 값에 의존합니다.

## SMTP

**이메일 / SMTP**에서 발신자 이름과 주소, 호스트, 포트, 사용자명, 비밀번호를 입력합니다. 465 포트는 암시적 TLS를 사용하고, 다른 포트는 서버가 지원하면 STARTTLS로 전환합니다.

저장한 뒤 테스트 이메일을 보내세요. SMTP는 멤버 초대, 비밀번호 재설정, 이메일 확인에 필요합니다. 테스트 수신 후 이메일 확인을 활성화하세요.

## SAML SSO

**워크스페이스 설정 → Single Sign-On**에서 이름과 이메일 도메인을 지정합니다. 표시된 Entity ID, ACS URL, 로그인 URL, Metadata URL을 IdP에 등록합니다. IdP 메타데이터 URL 사용을 권장하며, 없으면 로그인 URL, Entity ID, X.509 인증서를 직접 입력합니다.

활성화 전 **구성 테스트**와 **로그인 테스트**를 실행하세요. 테스트 중에는 비밀번호로 로그인한 관리자 세션을 유지하고, 다른 관리자가 성공할 때까지 대체 로그인 방식을 비활성화하지 마세요.
