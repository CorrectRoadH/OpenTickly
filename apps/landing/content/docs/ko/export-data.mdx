## ZIP 내려받기

1. 워크스페이스의 **설정** → **데이터 내보내기**를 엽니다.
2. **내보낼 항목 선택:**에서 필요한 항목을 선택합니다.
3. **Export**를 누릅니다.

ZIP에는 `manifest.json`과 선택한 항목의 JSON 파일이 들어갑니다. 프로젝트, 프로젝트 멤버, 작업, 고객, 태그, 워크스페이스 멤버, 조직 그룹, 설정, 저장된 보고서 정의를 선택할 수 있습니다. 일부 항목은 **projects_users**, **project_tasks**, **team**, **teams**, **workspace_settings**, **custom_reports**, **scheduled_reports**라는 키로 표시됩니다. 프로젝트 멤버는 `projects_users/<project-id>.json`, 워크스페이스 멤버는 `workspace_users.json`에 저장됩니다. 정의를 내보내도 보고서 예약 발송이 활성화되지는 않습니다.

시간 기록은 ZIP에 포함되지 않습니다. 인스턴스를 복구하려면 [데이터베이스 백업](/ko/docs/backup-and-upgrade)을 사용하세요.

## 시간 기록 내려받기

1. **시간 항목 내보내기**에서 **시작일**와 **종료일**를 고릅니다.
2. **내보내기 형식**에서 **CSV** 또는 **PDF**를 선택합니다.
3. **내보내기**를 누릅니다.

선택한 기간에 로그인 계정이 기록한 시간을 여러 워크스페이스에 걸쳐 내보냅니다. 팀 전체의 기록이 아니며, 워크스페이스를 바꿔도 이 내보내기의 범위는 제한되지 않습니다. 프로젝트와 고객을 확인하세요. 진행 중인 타이머는 제외됩니다. CSV 열은 `Description,Project,Client,Start,Stop,Duration,Billable,Tags`이며 시간은 `HH:MM:SS` 형식입니다. PDF는 읽기용입니다. 건수를 확인하고 긴 기간은 나눠서 내보내세요.

## Toggl Track으로 옮기기

CSV를 그대로 가져올 수는 없습니다. 스프레드시트에서 먼저 수정하세요.

1. `Email` 열을 추가하고 각 기록 소유자의 Toggl 이메일을 입력합니다.
2. 올바른 시간대로 `Start`를 `Start date`와 `Start time`으로 나누고 원래 `Start`, `Stop` 열은 삭제합니다.
3. 설명, 프로젝트, 고객, 시간, 청구 여부, 태그를 유지합니다. UTF-8 CSV로 저장하고 [Toggl 가져오기 안내](https://support.toggl.com/en-us/article/editing-and-uploading-a-csv-file-bk155h/)를 확인합니다.
4. Toggl 워크스페이스 관리자로 일부 기록을 먼저 가져와 날짜와 합계를 비교한 뒤 나머지를 옮깁니다.

ZIP은 Toggl 복원 파일이 아닙니다. CSV로는 권한, 설정, 보고서, 첨부 파일을 옮길 수 없으며, 이 시간 내보내기에는 작업과 요율도 없습니다. 청구 여부 가져오기는 Toggl 요금제에 따라 다릅니다. 각 팀원이 자기 기록을 따로 내보내세요.

[보고서](/ko/docs/reports)의 **내보내기**는 그룹별 합계를 내려받으므로 개별 시간 기록을 가져오는 데 쓸 수 없습니다.
