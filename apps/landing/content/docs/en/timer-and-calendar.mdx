## Start a timer or add past work

1. Open **Timer** and describe the work.
2. Pick a project and tags, then press the play button.
3. Stop the timer when you finish.

To add past work manually, create an entry in the calendar and set its start and stop times. The profile field **Manual entry mode** does not currently switch the timer composer into manual mode.

## Use the keyboard

Type `@` for projects or `#` for tags at the start of the description or after a space. Type to narrow the list, use the arrow keys to choose, and press Enter. Escape closes the picker.

In your profile under **Keyboard shortcuts**, turn these off individually:

- **Allow using @ shortcut to assign a Project in the Timer Description field**
- **Allow using # shortcut to assign a Tag in the Timer Description field**

When focus is outside an input field, `n` focuses the description, `s` stops the running timer, and `?` opens the shortcut list.

## Edit the calendar or list

In **Calendar**, drag across an empty time slot to create an entry. Drag an existing entry to move it; drag its edge to change its duration. Click an entry to edit it. Right-click for actions such as **Duplicate**, **Split**, **Copy description**, or **Delete**.

In **List view**, select entry checkboxes and choose **Edit** to change their description, project, tags, date, or billable status together. Review the selected entries before saving.

## Reuse favorites

Right-click a calendar entry and choose **Pin as favorite**. Open the sidebar with **Toggle goals and favorites**; click a favorite to start a new timer with its saved description, project, and tags.

See [Reports](/docs/reports) to review your time, or [Export your data](/docs/export-data) to download it.
