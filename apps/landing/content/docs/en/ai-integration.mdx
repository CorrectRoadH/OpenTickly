[`toggl-cli`](https://github.com/CorrectRoadH/toggl-cli) lets Claude Code, OpenClaw, Hermes Agent, Codex, Cursor, and other AI agents use OpenTickly from the command line. They can track time, start and stop timers, and manage projects and tags for you.

It comes in two parts:

- `toggl`: the command-line tool itself
- `SKILL.md`: a skill file that teaches your agent how to use it

## Install

```bash
npm install -g @correctroadh/toggl-cli

npx skills add CorrectRoadH/toggl-cli
```

## Configure

The CLI works with both Toggl and OpenTickly, and talks to Toggl by default. Toggl only allows 30 API requests per hour, which an agent can use up in a minute, so we recommend using it with OpenTickly.

To point it at your instance, add `--api-type opentoggl` and `--api-url` when you log in:

```bash
toggl auth <YOUR_API_TOKEN> --api-type opentoggl --api-url https://your-instance.com/api/v9
```

You can find `YOUR_API_TOKEN` in the OpenTickly web app under your avatar → Profile → API Token.

Not sure what to do with it next? [Practices & Workflow](/docs/practices) has a few real examples: letting the agent start timers, giving it your weekly plan, and a nightly AI review.
