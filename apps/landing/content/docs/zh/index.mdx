title: OpenTickly 是什么

OpenTickly 是一个免费、隐私优先、AI 友好的 Toggl 替代方案。

OpenTickly 以前叫 OpenToggl，后来改了名。旧链接或讨论里看到的 OpenToggl，就是这个项目。

Toggl 是个很棒的产品，但是太贵，而且数据并不真的属于你。更头疼的是 30 次/小时的 API 限制 —— AI Agent 能在一分钟里把一个小时的额度全部用掉。

OpenTickly 的用法和 Toggl 保持一致：数据可以完整地从 Toggl 搬过来，也可以随时再搬回去，一条都不丢。原来的工作流和习惯都不用改，只是更便宜、更隐私、对 AI 更友好。

## 我们做哪些功能

我们只做 Toggl 已经有的功能，再加上不改变用户数据的扩展，比如实例管理、AI 相关的工具。这样你随时都能带着数据回到 Toggl，不会被绑死。

如果某个功能会让数据变成 Toggl 存不下的样子，哪怕它很实用、很多人想要，也不会被接受。
