这篇带你从新注册的账号走到第一份报表。可以先用在线版试试，也可以直接部署到自己的服务器上。

## 选择使用方式

| 方式     | 适合谁                       | 怎么开始                                                           |
| -------- | ---------------------------- | ------------------------------------------------------------------ |
| 在线体验 | 想先确认界面和工作流是否合适 | 打开 [track.opentoggl.com](https://track.opentoggl.com) 并注册账号 |
| 自托管   | 想让数据留在自己机器上       | 阅读 [Docker 自托管指南](/zh/docs/self-hosting)                    |

两种方式用的是同一个应用。自托管的话数据都在你自己机器上，备份和升级也由你自己来。

## 创建账号和工作区

1. 使用姓名、邮箱和密码注册。
2. 打开引导流程创建的工作区。
3. 在团队开始记时前确认工作区时区。
4. 如果希望第一条记录进入项目报表，先创建一个项目。

所有东西都放在工作区里：客户、项目、标签、成员、费率和时间记录。报表和团队协作也都按工作区来。

## 记录第一条时间

1. 打开 **计时器**。
2. 输入清楚的描述，例如“编写上手文档”。
3. 选择项目和可选标签。
4. 开始计时，工作完成后停止。

如果已经知道开始和结束时间，用手动记录就行。日历视图和列表视图里是同一批记录，哪个顺手用哪个。

## 查看时间去了哪里

打开 **报表**，选好日期范围。先看汇总，想看细一点再按项目、客户、成员、标签、是否计费或描述来筛选和分组。

刚开始用的时候，可以检查这几点：

- 总时长是否符合预期？
- 时间是否归到了正确的项目和客户？
- 计费与非计费时间是否区分正确？
- 团队成员是否用相同标签表示相同类型的工作？

## 接入已有数据和工具

- 从 Toggl Track 搬迁：阅读[从 Toggl 迁移到 OpenTickly](/zh/docs/migrate-from-toggl)。
- 复用 CLI、脚本或 Agent：阅读 [Toggl API 兼容说明](/zh/docs/api-compatibility)。
- 让 Agent 自动记录时间：接入 [toggl-cli 和 AI Agent](/zh/docs/ai-integration)。

## 建议的下一步

1. 按你想在报表里看到的样子，建好客户和项目。
2. 邀请团队成员，确认他们的角色。
3. 如果是自托管，把数据库备份安排上。
4. 养成一个复盘习惯，比如每天看一眼计时器，或每周看一次项目报表。

项目和标签先少建一点，能坚持用下去最重要。等你真的想在报表里看某个维度时，再加。
