[`toggl-cli`](https://github.com/CorrectRoadH/toggl-cli) 可以让 Claude Code、OpenClaw、Hermes Agent、Codex、Cursor 等 AI Agent 在命令行里操作 OpenTickly，帮你记录时间、开始和停止计时、管理项目与标签。

它包含两部分：

- `toggl`：命令行工具本身
- `SKILL.md`：技能文件，告诉 Agent 怎么用这个工具

## 安装

```bash
npm install -g @correctroadh/toggl-cli

npx skills add CorrectRoadH/toggl-cli
```

## 配置

这个 CLI 同时支持 Toggl 和 OpenTickly，默认连的是 Toggl。但 Toggl 每小时只允许调用 30 次 API，Agent 一分钟就能用完，所以推荐配合 OpenTickly 使用。

要连到你自己的实例，登录时加上 `--api-type opentoggl` 和 `--api-url`：

```bash
toggl auth <YOUR_API_TOKEN> --api-type opentoggl --api-url https://your-instance.com/api/v9
```

`YOUR_API_TOKEN` 在 OpenTickly 网页里点头像 → Profile → API Token 就能找到。

装好之后怎么用？[实践 / 工作流](/zh/docs/practices)里有几个真实例子：让 Agent 帮你开计时、把周计划交给 Agent、每晚让 AI 做时间复盘。
