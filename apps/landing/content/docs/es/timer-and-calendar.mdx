## Empieza a registrar

1. Abre **Temporizador** y describe el trabajo.
2. Elige proyecto y etiquetas y pulsa el botón de reproducción.
3. Detén el temporizador al terminar.

Para añadir trabajo pasado, crea un registro en el calendario y ajusta el inicio y el final. El campo **Modo de entrada manual** del perfil no cambia actualmente la barra del temporizador al modo manual.

## Atajos

Escribe `@` para elegir proyecto o `#` para etiquetas, al principio de la descripción o después de un espacio. Sigue escribiendo para filtrar, elige con las flechas y confirma con Enter. Escape cierra el selector.

En **Atajos de teclado** del perfil puedes desactivar:

- **Permitir el uso del atajo @ para asignar un Proyecto en el campo de descripción del temporizador**
- **Permitir el uso del atajo # para asignar una Etiqueta en el campo de descripción del temporizador**

Fuera de los campos de entrada, `n` enfoca la descripción, `s` detiene el temporizador y `?` muestra los atajos.

## Calendario y lista

En **Calendario**, arrastra sobre un hueco para crear un registro. Arrastra un registro para moverlo o su borde para cambiar la duración. Haz clic para editarlo; con el botón derecho puedes **Duplicar**, **Dividir**, **Copiar descripción** o **Eliminar**.

En **Vista de lista**, marca varios registros y pulsa **Editar** para cambiar descripción, proyecto, etiquetas, fecha o estado facturable. Revisa la selección antes de guardar.

## Favoritos

Haz clic derecho en un registro del calendario y elige **Fijar como favorito**. Abre la barra lateral con **Alternar objetivos y favoritos** y pulsa un favorito para iniciar otro temporizador con su descripción, proyecto y etiquetas.
