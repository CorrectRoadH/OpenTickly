[`toggl-cli`](https://github.com/CorrectRoadH/toggl-cli) permite que Claude Code, OpenClaw, Hermes Agent, Codex, Cursor y otros agentes de IA usen OpenTickly desde la línea de comandos. Pueden registrar tiempo, iniciar y parar temporizadores y gestionar proyectos y etiquetas por ti.

Tiene dos partes:

- `toggl`: la herramienta de línea de comandos en sí
- `SKILL.md`: un archivo de habilidad que le enseña a tu agente a usarla

## Instalación

```bash
npm install -g @correctroadh/toggl-cli

npx skills add CorrectRoadH/toggl-cli
```

## Configuración

El CLI funciona tanto con Toggl como con OpenTickly, y por defecto se conecta a Toggl. Toggl solo permite 30 peticiones a la API por hora, y un agente puede gastarlas en un minuto, así que te recomendamos usarlo con OpenTickly.

Para que apunte a tu instancia, añade `--api-type opentoggl` y `--api-url` al iniciar sesión:

```bash
toggl auth <YOUR_API_TOKEN> --api-type opentoggl --api-url https://your-instance.com/api/v9
```

Encontrarás `YOUR_API_TOKEN` en la web de OpenTickly: tu avatar → Profile → API Token.

¿No sabes qué hacer con él después? En [Prácticas / Flujo de trabajo](/es/docs/practices) hay algunos ejemplos reales: dejar que el agente inicie los temporizadores, pasarle tu plan semanal y una revisión nocturna con IA.
