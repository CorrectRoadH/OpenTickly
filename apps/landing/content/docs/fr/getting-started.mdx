Ce guide vous accompagne de la création du compte jusqu'à votre premier rapport. Essayez d'abord la démo en ligne, ou installez OpenTickly sur votre propre serveur.

## Choisir comment utiliser OpenTickly

| Option           | Idéal pour                                                   | Que faire                                                                    |
| ---------------- | ------------------------------------------------------------ | ---------------------------------------------------------------------------- |
| Démo en ligne    | Essayer avant d'installer quoi que ce soit                   | Ouvrez [track.opentoggl.com](https://track.opentoggl.com) et créez un compte |
| Auto-hébergement | Garder l'application et la base de données sur votre serveur | Suivez le [guide d'auto-hébergement Docker](/fr/docs/self-hosting)           |

C'est la même application dans les deux cas. En auto-hébergement, vos données restent chez vous, mais les sauvegardes et les mises à jour sont à votre charge.

## Créer votre compte et votre espace de travail

1. Inscrivez-vous avec votre nom, votre adresse e-mail et un mot de passe.
2. Ouvrez l'espace de travail créé pendant l'accueil.
3. Vérifiez le fuseau horaire de l'espace avant d'y enregistrer l'activité de l'équipe.
4. Ajoutez un projet si vous voulez que votre première entrée apparaisse dans les rapports par projet.

Tout se passe dans un espace de travail : projets, clients, tags, membres, tarifs facturables et entrées de temps. Les rapports et le partage en équipe fonctionnent aussi par espace de travail.

## Enregistrer votre première entrée de temps

1. Ouvrez **Minuteur**.
2. Saisissez une description concrète, par exemple `Rédiger le guide d'accueil`.
3. Choisissez un projet et, si vous voulez, des tags.
4. Démarrez le minuteur, puis arrêtez-le quand le travail est terminé.

Si vous connaissez déjà l'heure de début et de fin, passez en mode manuel. Les vues calendrier et liste affichent les mêmes entrées : modifiez-les dans celle que vous préférez.

## Voir où est passé votre temps

Ouvrez **Rapports** et choisissez une période. Commencez par le résumé, puis filtrez ou regroupez par projet, client, utilisateur, tag, statut facturable ou description quand vous voulez plus de détails.

Quelques points à vérifier dès le début :

- Le total correspond-il au temps que vous pensiez avoir enregistré ?
- Les entrées sont-elles rattachées au bon projet et au bon client ?
- Les entrées facturables et non facturables sont-elles bien séparées ?
- Les membres de l'équipe utilisent-ils les mêmes tags pour le même type de travail ?

## Reprendre vos données ou vos intégrations

- Vous venez de Toggl Track : suivez [Migrer de Toggl vers OpenTickly](/fr/docs/migrate-from-toggl).
- Vous voulez réutiliser un CLI, un script ou un agent : lisez [Compatibilité avec l'API Toggl](/fr/docs/api-compatibility).
- Vous voulez qu'un agent enregistre votre temps : branchez [toggl-cli et un agent IA](/fr/docs/ai-integration).

## Et ensuite

1. Organisez vos clients et projets comme vous voulez les voir dans les rapports.
2. Invitez vos collègues et vérifiez leurs rôles.
3. Si vous êtes en auto-hébergement, [mettez en place des sauvegardes de la base de données](/fr/docs/backup-and-upgrade).
4. Prenez une habitude de suivi, par exemple jeter un œil au minuteur chaque jour ou au rapport par projet chaque semaine.

Commencez avec aussi peu de projets et de tags que possible, juste ce que vous arriverez à tenir. N'en ajoutez que lorsqu'un rapport dont vous avez vraiment besoin l'exige.
