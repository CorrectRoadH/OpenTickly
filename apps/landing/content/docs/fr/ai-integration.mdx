[`toggl-cli`](https://github.com/CorrectRoadH/toggl-cli) permet à Claude Code, OpenClaw, Hermes Agent, Codex, Cursor et d'autres agents IA d'utiliser OpenTickly en ligne de commande. Ils peuvent suivre votre temps, démarrer et arrêter des minuteurs et gérer vos projets et tags à votre place.

Il y a deux morceaux :

- `toggl` : l'outil en ligne de commande lui-même
- `SKILL.md` : un fichier de compétence qui explique à votre agent comment s'en servir

## Installation

```bash
npm install -g @correctroadh/toggl-cli

npx skills add CorrectRoadH/toggl-cli
```

## Configuration

Le CLI fonctionne avec Toggl comme avec OpenTickly, et se connecte à Toggl par défaut. Toggl n'autorise que 30 requêtes API par heure, qu'un agent peut épuiser en une minute : on vous conseille donc de l'utiliser avec OpenTickly.

Pour le faire pointer vers votre instance, ajoutez `--api-type opentoggl` et `--api-url` au moment de vous connecter :

```bash
toggl auth <YOUR_API_TOKEN> --api-type opentoggl --api-url https://your-instance.com/api/v9
```

Vous trouverez votre `YOUR_API_TOKEN` dans l'application web d'OpenTickly : avatar → Profil → Jeton API.

Vous ne savez pas trop quoi en faire ensuite ? La page [Pratiques / Flux de travail](/fr/docs/practices) donne quelques exemples concrets : laisser l'agent démarrer les minuteurs, lui donner votre plan de la semaine, et une rétrospective IA chaque soir.
